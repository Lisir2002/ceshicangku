# blog_lab 运行说明（phpStudy 2016）

> **教学靶场，故意包含漏洞，仅限本地实验，禁止公网部署。**

## 一、运行环境

| 项 | 要求 |
| --- | --- |
| Web 环境 | **phpStudy 2016**（内置 Apache + MySQL） |
| PHP | **5.6 及以上**（在 phpStudy 中切换版本；需启用 `mysqli`、`gd`、`openssl` 扩展） |
| 数据库 | MySQL（phpStudy 自带，默认账号 **root / root**） |

## 二、部署步骤

1. **放入 WWW 目录**：将本项目代码放入 phpStudy 2016 的 `WWW` 目录下。
2. **启动服务**：在 phpStudy 面板启动 **Apache** 和 **MySQL**。
3. **初始化数据库**：浏览器访问 `init_db.php` 完成建库、建表并写入弱口令账号。
   - 地址：`http://localhost/init_db.php`
4. **开始测试**：浏览器访问 `index.php` 进入登录页。
   - 地址：`http://localhost/index.php`
5. **数据库账号**：默认 **root / root**，可根据本地 phpStudy 配置修改 [config.php](../config.php) 的 `db` 段。

> **路径提示**：若代码放在 `WWW/blog_lab/` 子目录下，访问地址相应变为
> `http://localhost/blog_lab/init_db.php` 与 `http://localhost/blog_lab/index.php`。

## 四、常见问题

| 现象 | 处理 |
| --- | --- |
| 提示“数据库连接失败” | 核对 [config.php](../config.php) 的 `db` 段（host / port / user / pass）与 phpStudy 的 MySQL 账号密码是否一致；确认 MySQL 已启动 |
| 初始化提示“仅允许在本机运行” | 用 `localhost` 或 `127.0.0.1` 访问，不要用局域网 IP |
| 中文乱码 | 代码已在建连后设置 `utf8mb4`；确认 MySQL 版本 ≥ 5.5.3 |
| 验证码图片不显示 | 在 phpStudy 中启用 `gd` 扩展 |
| 样式 / 图标异常 | 确认 `assets/vendor/layui/` 目录随代码一并拷贝 |
